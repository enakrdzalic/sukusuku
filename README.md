# 스쿠스쿠

스쿠스쿠 일본어 독학 첫걸음(1권)을 따라가는 학습 앱입니다. 12단원을 단어 카드, 독해, 확인 문제 순서로 엽니다.

- 단어 카드: 앞면은 일본어, 뒷면은 한국어·영어·연상입니다. 맞으면 빠지고 틀리면 맨 뒤로 갑니다. 점수 = 카드 수 ÷ 시도 횟수 × 100. 80%를 넘으면 독해가 열립니다.
- 독해: 단원 문법과 단어로 쓴 글과 이해 문제입니다. 80%를 넘으면 확인 문제가 열립니다.
- 확인 문제: 교재 문제를 직접 씁니다. 80% 이상이면 다음 단원이 열립니다.
- 틀린 단어는 약점 복습에 모이고, 진도는 이 브라우저의 localStorage에 남습니다.

## 개발

```bash
npm ci
npm run dev
```

앱은 [http://localhost:3000](http://localhost:3000) 에서 열립니다.

```bash

```
